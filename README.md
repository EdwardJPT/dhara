# Dhara Web App

Code for deployed web app at https://dhara.work/

## About

**The Name "Dhara"**

The name Dhara" (dhārā / धारा) comes from Sanskrit, meaning  "flow," "stream," or "continuous current". This project was meant to help me to get into the flow state easily when I'm working with a lot of my projects, while also serve as a portfolio project to apply for jobs, and lastly to learn about Go programming language. Tho I should admit I don't know Sanskrit and not sure if the use of the word is correct!

**Purpose**

Dhara was built as a portfolio project to demonstrate clean and efficient web app. I built this web app without heavy JS frameworks, prefering for compiled Preact sent as plain JavaScript to the frontend instead. The web app provides a simple, clutter-free space to organize tasks around distinct projects, keeping work neatly separated so tasks from different projects never mix together.

**Key Features**
* **Project-Centric:** Group tasks cleanly by workspace and goals.
* **Fast & Lightweight:** Designed for low latency and high responsiveness.
* **Minimalist UI:** Clean interface focused on task completion.
* **Instant Demo:** Explore full capabilities without registering.

## Tech Stack

* **Frontend:** Go Templates, PreactJS, and 1 page with HTMX
* **Styling:** TailwindCSS
* **Backend:** Go with Chi, SQLite, and Nginx inside Podman
* **Deployment:** AWS EC2 and GitHub Actions CI/CD
