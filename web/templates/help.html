Help & FAQ

Frequently asked questions and getting started guide

How do I get started?

You can create a free account via the Sign Up page or click View Demo on the main login page to explore features instantly without creating an account.

Is this application free to use?

Yes, Dhara is completely free to use. It is maintained as an open portfolio application.

How does Demo Mode work?

Demo Mode loads a pre-populated sandbox environment allowing you to test task management features. Any changes made in demo mode may be reset periodically.

I forgot my password. How can I reset it?

Since this is a portfolio application, automated password reset emails are currently disabled. Please contact the administrator or register a new testing account.
